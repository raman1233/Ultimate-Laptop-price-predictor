## Color Scheme

### Dark Theme (Current)
- **Background**: Almost black (#030303)
- **Text**: Off-white (#FAFAFA)
- **Primary**: Bright Blue (#0099FF) - Actions, highlights
- **Secondary**: Purple (#9966FF) - Accents
- **Accent**: Red (#FF0000) - Warnings, special highlights
- **Muted**: Dark Gray (#404040) - Secondary text
- **Cards**: Semi-transparent white (5%) with blur effect

### Component Colors

```
Glass Cards
├─ Border: 10% white with transparency
├─ Background: 5% white with backdrop blur
└─ Hover: 10% white border, 10% white background

Buttons (Primary)
├─ Gradient: Blue → Purple
├─ Text: White
└─ Hover: Larger shadow, slight scale up

Input Fields
├─ Border: 10% white
├─ Background: 5% white with blur
├─ Focus: Blue border, blue ring
└─ Text: Off-white

Prices & Important Numbers
├─ Color: Gradient Blue → Purple → Red
└─ Font: Extra large, bold
```

## Typography

### Headings
- **H1** (Page Title): 48-60px, bold
- **H2** (Section Headers): 36-48px, bold
- **H3** (Subsection Headers): 24-36px, bold

### Body Text
- **Regular**: 16px, medium weight
- **Label**: 14px, medium weight
- **Small**: 12px, regular weight
- **Extra Small**: 12px, regular weight

### Font Family
System font stack (efficient, works everywhere)

## Component Styles

### Glass Card
```
- Border-radius: 12px
- Border: 1px solid white/10%
- Background: white/5% with backdrop blur
- Padding: 24px
- Transition: 300ms ease
- Hover: border white/20%, background white/10%, shadow
```

### Gradient Text
```
- Gradient: Blue → Purple → Red
- Background-clip: text
- Text-transparent: true
- Font-weight: bold
```

### Buttons

**Primary Button**
```
- Background: Gradient (Blue → Purple)
- Text: White
- Padding: 12px 32px
- Border-radius: 8px
- Shadow: 0 4px 15px rgba(0,0,0,0.3)
- Hover: shadow 0 6px 20px, slight scale
- Active: scale 0.95
```

**Secondary Button**
```
- Border: 1px white/20%
- Background: white/5% with blur
- Text: Off-white
- Hover: bg white/10%, border white/40%
```

### Form Fields

**Select/Input**
```
- Border: 1px white/10%
- Background: white/5% with blur
- Padding: 12px 16px
- Border-radius: 8px
- Focus: border primary, ring primary/50%
- Transition: 300ms
```

### Price Display (Special)
```
- Border: 2px accent/50%
- Background: Gradient (accent/10% → secondary/10%)
- Padding: 32px
- Border-radius: 12px
- Text: Large, gradient colored
```

## Animations

### Loading Spinner
```
- Animation: spinning 360°
- Duration: 1s
- Loop: infinite
- Border: 4px semi-transparent
- Top border: primary color
```

### Fade In
```
- Animation: fade-in slide-in-from-bottom
- Duration: 500ms
- Easing: ease-out
```

### Hover Effects
```
- Cards: subtle shadow glow
- Buttons: scale 1.02 on hover
- Links: color transition
```

## Responsive Breakpoints

### Mobile (< 768px)
- Single column layout
- Larger touch targets (44px minimum)
- Full-width buttons
- Simplified spacing

### Tablet (768px - 1024px)
- Two column layouts where appropriate
- Moderate spacing
- Mixed layout

### Desktop (> 1024px)
- Three column layouts
- Full design with all effects
- Hover states active

## Accessibility Features

- **Color Contrast**: WCAG AA compliant
- **Focus States**: Clear blue outline
- **Keyboard Navigation**: All interactive elements accessible
- **Form Labels**: Proper label associations
- **Error Messages**: Clear and descriptive
- **Loading States**: Visual feedback
- **Screen Readers**: Semantic HTML

## Interactive Elements

### Dropdowns
```
- Click to open
- Keyboard navigation (arrows)
- Escape to close
- Shows selected value
```

### Sliders (Range Inputs)
```
- Thumb: Draggable circle
- Track: Shows current value
- Labels: Dynamic (e.g., "RAM: 8GB")
```

### Checkboxes
```
- Square checkbox
- Label text next to it
- Clickable entire area
- Checked state: Blue check mark
```

### Text Inputs
```
- Placeholder text
- Focus state: Blue border + glow
- Error state: Red border
```

## Special States

### Loading State
```
- Spinning animation
- "Analyzing Specifications..." text
- Button disabled
- Form fields disabled
```

### Error State
```
- Red border on card
- Red text for message
- Red accent icon
- Clear error message
```

### Success State
```
- Green accent color
- Checkmark icon
- Success animation
- Results display
```

### Empty State
```
- Placeholder text
- Icon or illustration
- Call to action
```

## Dark Mode Advantages

- Reduces eye strain
- Battery efficient (especially on OLED)
- Modern, professional appearance
- Great contrast with bright accents
- Aligns with tech industry aesthetic

---

## Visual Hierarchy

1. **Most Important**: Large price display (H1 size, gradient)
2. **Important**: Section headers (H2 size, gradient text)
3. **Secondary**: Labels and smaller text (muted gray)
4. **Least Important**: Hints and help text (extra muted)

## Whitespace Usage

- Large sections separated by 24px gap
- Form fields separated by 16px
- Cards have 24px padding
- Screen edges have 16px+ padding on mobile, 32px+ on desktop

---

This design creates a **modern, professional, and engaging** interface that makes users confident in using your ML price prediction tool.
